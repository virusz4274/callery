# **App Name**: CallOrganizer

## Core Features:

- File Ingestion: Ingest audio files from a specified directory (/injest/).
- File Parsing & Renaming: Parse audio files, rename them according to the naming convention, and move them to the appropriate directory.
- Directory Organization: Organize recordings into a structured folder hierarchy based on contact/number, year, and month.
- Database Entry Creation: Create a database entry for each processed audio file, including relevant metadata.
- Contact Sync: Synchronize contact list with Google Contacts using OAuth. Auto-update/move recordings if a number is added to contacts.
- Organized File Browser: Implement UI that organizes files in a manner so that it will improve user browsing experience.
- Search and Filter: Enable searching and filtering of recordings based on various criteria.

## Style Guidelines:

- Primary color: Deep blue (#1E3A8A) to inspire confidence and security in handling sensitive data.
- Background color: Light gray (#F0F4F8), providing a clean and unobtrusive backdrop.
- Accent color: Electric Purple (#7E57C2) to highlight important interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern, neutral, and readable qualities.
- Use clear, consistent icons to represent different file types, actions, and categories.
- A clean and intuitive layout, providing easy access to all features. HeroUI
- Subtle animations to provide feedback on actions and guide the user through the process.
