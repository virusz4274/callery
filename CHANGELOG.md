# Changelog

All notable changes to this project will be documented in this file.

## [v0.1.0] - 2026-02-02 (Beta)

### Added
- **Core**: Initial beta release of Call Memo (VoSift).
- **Recordings**: Upload, storage (Cloudflare R2), and playback.
- **Transcription**: Automated transcription via Soniox API.
- **Intelligence**: Summaries and insights via Google Gemini.
- **Contacts**: Google Contacts synchronization and management.
- **Billing**: Stripe integration for subscriptions and metered usage.
- **Admin**: Dashboard for user management and file browsing.
